GD 프레임 윈도우 카운터 (지오메트리 대시 2.2)

하는 일
  레벨 + 매크로(xdBot .gdr / .gdr.json, 이클립스 .gdr2) → 누름마다 몇 틱(1/240초) 안에 눌러야 하는지(윈도우),
  칸별 개수(17+ … 1), σ/s(24시간 안에 깨려면 필요한 정확도, NaNDL 식), OBS 오버레이 영상(.webm)

쓰는 법
  1) [레벨 파일 열기]로 .gmd/.txt, 또는 [게임 저장 파일에서 고르기]로 내가 만든 레벨 고르기 (게임 파일은 읽기만 함)
  2) [매크로 파일 열기]
  3) [계산] → 표, σ/s. [결과 저장]으로 csv/json, [OBS 오버레이 저장]으로 투명 영상
  OBS: 소스 추가 → 미디어 소스 → 저장한 .webm. 녹화 영상의 레벨 시작 순간과 맞춰 재생

알아 둘 것
  - 계산 엔진은 게임을 다시 만든 것이라 실제 게임과 다를 수 있음. 매크로가 엔진에서 죽으면 그 1초 전까지만 계산하고 알려 줌
  - 240틱 매크로만, 플랫포머 안 됨, 2인용 입력은 뺌
  - 글꼴 Pusab (Flat-it 프리웨어, fonts/Pusab_License.txt)

만들기 (소스에서): build.bat 실행 → dist\GD_FWC\GD_FWC.exe
